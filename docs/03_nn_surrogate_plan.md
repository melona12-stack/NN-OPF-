# 3~5단계 — NN 스터디 및 조류계산 대체모델 설계

## A. 신경망 기초 스터디 계획 (3단계)

아주 기초부터 필요하다고 하셨으니, **필요한 것만** 순서대로 적습니다.
전력계통 대체모델에 안 쓰이는 주제(RNN, Transformer, 생성모델 등)는 뺐습니다.

### A-1. 최소 필수 이론 (2주)

| 주제 | 왜 필요한가 | 우리 문제에서의 의미 |
|---|---|---|
| 선형회귀 → 다층 퍼셉트론(MLP) | 신경망은 "선형변환 + 비선형함수"의 반복 | 조류방정식도 결국 입력→출력 사상 |
| 활성화 함수 (ReLU, tanh, SiLU) | 비선형성의 원천 | 조류방정식은 **매끄러운** 비선형 → tanh/SiLU 가 ReLU 보다 유리할 수 있음 |
| 손실함수 (MSE, MAE, Huber) | 무엇을 "잘함"으로 정의할지 | 전압 오차를 어떤 노름으로 잴 것인가 |
| 역전파 (backpropagation) | 그래디언트 계산 원리 | 5단계에서 NN 을 OPF 제약으로 넣을 때 **그 미분값이 필요** |
| 최적화기 (SGD, Adam) | 학습이 실제로 굴러가는 방식 | 뉴턴법과 비교하면 이해가 빠름 |
| 일반화/과적합, 정규화 | 학습 데이터 밖에서도 동작해야 함 | 우리 목표 자체가 "본 적 없는 부하에서도 맞히기" |
| 정규화(normalization) | 입력 스케일 통일 | pu 단위라 이미 절반은 해결됨 |

**추천 자료**
- 3Blue1Brown, *Neural Networks* 영상 시리즈 — 직관 잡기 (한국어 자막)
- Andrej Karpathy, *Neural Networks: Zero to Hero* — 역전파를 직접 구현
- *Dive into Deep Learning* (d2l.ai) — 무료, PyTorch 예제 포함

### A-2. PyTorch 실습 (2주)

| 항목 | 확인 방법 |
|---|---|
| `Tensor`, `autograd` | 손으로 미분한 값과 `.backward()` 결과 비교 |
| `nn.Module`, `nn.Linear` | MLP 를 직접 정의 |
| `Dataset` / `DataLoader` | 조류계산 데이터를 배치로 공급 |
| 학습 루프 | train/val 분리, early stopping |
| 재현성 | 시드 고정, `torch.use_deterministic_algorithms(True)` |
| 저장/불러오기 | `state_dict` 체크포인트 |

**첫 연습 과제 (권장)**: $y = \sin(x_1)\cos(x_2)$ 를 MLP 로 근사해 보기.
매끄러운 비선형 함수 근사가 조류방정식 학습과 성질이 같습니다.

### A-3. 이 프로젝트에 특화된 심화 (2주)

| 주제 | 이유 |
|---|---|
| 물리정보 신경망 (PINN) | 손실함수에 조류방정식 잔차를 넣는 방식 |
| 그래프 신경망 (GNN) | 계통은 그래프. 토폴로지 변화에 일반화 가능 |
| 미분가능 최적화 | NN 을 최적화 문제 안에 넣는 방법 |
| 대체모델 기반 최적화 | 근사모델로 최적화할 때 생기는 문제들 |

## B. 대체모델 설계 (4단계)

### B-1. 무엇을 학습할 것인가 — 입출력 계약

참고자료(§1)의 직접변수/간접변수 구분을 그대로 따릅니다.

$$
f_\theta:\;
\underbrace{\left(P^{spec}_{PV\cup PQ},\; Q^{spec}_{PQ},\; |V|^{set}_{slack \cup PV}\right)}_{\text{입력 (직접변수)}}
\;\longmapsto\;
\underbrace{\left(|V|_{PQ},\; \theta_{PV \cup PQ}\right)}_{\text{출력 (간접변수)}}
$$

나머지 값($P_{slack}, Q_{slack}, Q_{PV}$)은 예측된 전압에서 **닫힌 식**
$S = V\overline{YV}$ 로 바로 계산합니다. **학습하지 마세요** — 정확도만 떨어집니다.

> **설계 원칙**: 닫힌 식으로 구할 수 있는 건 절대 학습시키지 않는다.

### B-2. 표현 방식 선택지 (M3 에서 실험으로 결정)

| 항목 | 후보 A | 후보 B | 판단 기준 |
|---|---|---|---|
| 좌표계 | 극좌표 $(\|V\|, \theta)$ | 직교좌표 $(e, f)$ | 극좌표는 $\theta$ 의 감김(wrap) 문제, 직교는 크기 제약 표현이 어려움 |
| 출력 | 절대값 | **기저 케이스로부터의 편차** | 편차 학습이 보통 훨씬 쉬움 (출력 범위가 좁음) |
| 정규화 | 표준화 | min-max | 부하 분포에 의존 |
| 손실 | MSE | MSE + 조류방정식 잔차 | 후자가 PINN 방식 |

**초기 권장 조합**: 극좌표 + 기저 케이스 편차 + 표준화 + MSE
→ 가장 단순한 조합으로 먼저 기준선을 만들고, 하나씩 바꿔가며 비교.

### B-3. 데이터 생성 파이프라인

```
부하 샘플링              뉴턴-랩슨              (입력, 라벨) 저장
(Pd, Qd) ~ 분포   ──►   solve_power_flow  ──►   HDF5 / npz
                         (우리 구현, 검증 완료)
```

**샘플링 설계 — 여기가 논문 재현성의 핵심입니다**

| 항목 | 권장 |
|---|---|
| 부하 배율 | 기저 대비 $[0.6, 1.4]$ 균등, 혹은 실측 프로파일 기반 |
| 상관관계 | 모선별 독립 샘플링은 비현실적 → 전역 배율 + 모선별 잡음 |
| 역률 | $Q_d/P_d$ 를 고정할지 독립 변동시킬지 명시 |
| 발산 처리 | 수렴 실패 샘플은 **버리지 말고 기록** (분포 이해에 필요) |
| 데이터 규모 | 계통 크기별 학습곡선으로 결정 (일단 case9: 1만, case118: 10만 목표) |

**반드시 지킬 것**: 샘플링 코드는 시드를 받아 완전히 재현 가능해야 하고,
생성 설정을 데이터 파일과 함께 저장해야 합니다.

### B-4. 평가 지표 — 참고자료 기준선을 반드시 넘을 것

| 지표 | 정의 | 목표 |
|---|---|---|
| 전압 크기 오차 | $\max_i \| \|V\|_i^{NN} - \|V\|_i^{NR} \|$ | < 0.001 pu (0.1%) |
| 전압 위상 오차 | $\max_i \|\theta_i^{NN} - \theta_i^{NR}\|$ | < 0.001 rad |
| 전력 오차 | 예측 전압으로 계산한 $S$ 와 지정값의 차 | < 0.5% |
| 조류방정식 잔차 | $\|f(x^{NN})\|_\infty$ | < 1e-3 pu |
| 추론 시간 | 배치 1000건 기준 | 뉴턴-랩슨 대비 100배 이상 |

**비교군은 반드시 포함**: DC 조류계산, 고정점 선형화, (가능하면) Bernstein2017 LP.
참고자료가 제시한 **전압 0.2% / 전력 1.5%** 를 넘지 못하면 NN 을 쓸 이유가 없습니다.

## C. 대체모델을 포함한 OPF (5단계)

### C-1. 세 가지 통합 방식

#### (c) 웜스타트 — **여기서 시작하세요**

```
부하 ──► NN ──► 예측 전압/출력 ──► NLP 솔버 초기치 ──► 정확한 OPF 해
```

| | |
|---|---|
| 장점 | **항상 정확한 해**. NN 이 틀려도 답은 맞음. 구현 하루면 됨. |
| 단점 | 속도 향상 폭이 제한적 (반복 수만 줄어듦) |
| 위험 | 낮음 — 실패해도 기존 OPF 로 되돌아감 |

> 우리 `solve_acopf(warm_start=True)` 가 이미 이 구조입니다.
> 지금은 뉴턴-랩슨으로 웜스타트하는데, 그 자리에 NN 을 넣기만 하면 됩니다.

#### (a) 제약 대체 — 논문의 본론

```
min  비용
s.t. NN_θ(x) = 0      ← 조류방정식 대신 학습된 잔차 함수
     상자 제약
```

| | |
|---|---|
| 장점 | 개념적으로 가장 깔끔. 참고자료 아키텍처와 정확히 일치. |
| 단점 | NN 이 비볼록 → 국소해/수렴 문제. ReLU 면 미분 불연속. |
| 필요 기술 | NN 의 야코비안을 솔버에 전달 (PyTorch `autograd.functional.jacobian`) |
| 팁 | 활성화 함수를 **매끄럽게**(tanh/SiLU) 쓰면 수렴이 훨씬 안정적 |

#### (b) 종단간 예측 — 가장 빠르지만 가장 위험

```
부하 ──► NN ──► OPF 해 (Pg, Vm) 직접 출력
```

| | |
|---|---|
| 장점 | 추론 한 번. 가장 빠름. |
| 단점 | 제약 위반을 통제할 수 없음 → **사영/보정 단계 필수** |
| 연구 주제 | 실행가능성 복원(feasibility restoration), 위반량 상한 |

### C-2. 평가 프로토콜 — **2단 검증을 반드시**

참고자료가 경고한 그 함정을 피하는 방법입니다.

```
1단: NN-OPF 를 푼다            → 해 x*
2단: x* 의 발전지령을 진짜      → 실제 전압 V_real
     뉴턴-랩슨에 재투입
3단: V_real 이 전압/조류 한계를 지키는가?   ← 진짜 지표
```

**보고해야 할 표**

| 방식 | 비용 | 비용 갭 | 계산시간 | **실제 제약 위반율** | **최대 위반량** |
|---|---|---|---|---|---|
| 정확한 AC-OPF | 기준 | 0% | 기준 | 0% | 0 |
| DC-OPF | | | | | |
| NN 웜스타트 (c) | | | | | |
| NN 제약 (a) | | | | | |
| NN 종단간 (b) | | | | | |

> 이 표 하나가 논문 실험 섹션의 뼈대입니다. **"실제 제약 위반율" 열이 비어
> 있으면 논문이 되지 않습니다.**
